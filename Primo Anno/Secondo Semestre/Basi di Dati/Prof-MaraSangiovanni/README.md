## 🛠️ Strumenti per Diagrammi E-R e UML (Senza Watermark)

Durante le esercitazioni e la prova scritta/progettuale (spesso integrata con *Programmazione Object Oriented*) è necessario modellare schemi **Entità-Relazione (E-R)**, ristrutturazioni e diagrammi **UML** (nella cartella [`esercizi/`](./esercizi) trovi anche diversi progetti in formato `.mdj` / `.mfj` realizzati con StarUML).

### Alternative gratuite e ufficiali per studenti Unina
* **[Draw.io / diagrams.net](https://app.diagrams.net/)** *(Web & Desktop — Open Source)*: Zero watermark, template completi per notazione E-R (Chen / Atzeni) e UML 2.5, esportazione diretta in PDF/SVG/PNG.
* **[Visual Paradigm Academic / Community](https://www.visual-paradigm.com/editions/community/)**: Gratuito e senza watermark per uso non commerciale/didattico, ottimo per schemi E-R, generazione DDL SQL e diagrammi delle classi UML.
* **JetBrains DataGrip & IntelliJ IDEA Ultimate** *(100% gratis con `@studenti.unina.it` tramite il [GitHub Student Developer Pack](../../../../info-generali/guida-github-education.md))*: Generazione e visualizzazione automatica dei diagrammi relazionali direttamente dal database PostgreSQL/MySQL/Oracle.
* **[PlantUML](https://plantuml.com/) / [Mermaid](https://mermaid.js.org/)**: Ideali per chi preferisce generare diagrammi UML ed E-R direttamente da codice/Markdown.

### Nota per file `.mdj` (StarUML)
* Per aprire e modificare i file `.mdj` presenti in [`esercizi/`](./esercizi) è possibile usare [StarUML](https://staruml.io/) (la versione di valutazione gratuita apre e salva tutti i file `.mdj`, applicando solo una filigrana in fase di export immagine; riferimento community precedentemente archiviato: [rimozione watermark StarUML 7](https://github.com/rodyuzuriaga/Get-full-version-of-StarUML-7.0.0-Pro-Remove-Watermark)).
