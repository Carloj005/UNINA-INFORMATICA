# Progetti ed Esercizi Intercorso — Analisi e Progettazione di Strutture Dati (APSD)

Questa directory raccoglie in ordine cronologico le specifiche ufficiali, i diagrammi UML delle gerarchie di interfacce/classi e i template Java (`.zip` ed estratti) dei progetti / esercizi intercorso assegnati nel corso di **Analisi e Progettazione di Strutture Dati** (Prof. Massimo Benerecetti & Prof. Fabio Mogavero).

---

## 📅 Archivio Cronologico delle Tracce

### 📂 [`A.A. 2026-2027`](./A.A.%202026-2027/) — Ottobre 2026 (A.A. 2026/2027)
* **Argomento:** *Vettori, Liste, Deq e Insiemi di Dati Generici* in Java
* **File principali:**
  * [`Specifica_Esercizio_Intercorso_2026-2027.pdf`](./A.A.%202026-2027/Specifica_Esercizio_Intercorso_2026-2027.pdf) — Specifica ufficiale dell'esercizio intercorso, criteri di valutazione e riferimenti bibliografici
  * [`Template_2026-2027.zip`](./A.A.%202026-2027/Template_2026-2027.zip) — Archivio originale del template ufficiale fornito agli studenti
  * [`template/`](./A.A.%202026-2027/template/) — Struttura estratta del template contenente:
    * [`Diagrams.pdf`](./A.A.%202026-2027/template/Diagrams.pdf) — Diagramma della gerarchia di interfacce e classi (nero: dichiarazione astratta, verde: default, blu: overriding, rosso: ridichiarazione astratta)
    * [`readme.md`](./A.A.%202026-2027/template/readme.md) — Istruzioni per il completamento degli scheletri e comandi di build (`make support`, `make test`, `make runtest`, `make runtestseq`, `make runtestdeq`, `make runtestcol`)
    * [`makefile`](./A.A.%202026-2027/template/makefile) / [`winbuild.ps1`](./A.A.%202026-2027/template/winbuild.ps1) — Script di compilazione ed esecuzione test JUnit 5 per Linux/macOS e Windows PowerShell
    * [`apsd/`](./A.A.%202026-2027/template/apsd/) & [`zapsdtest/`](./A.A.%202026-2027/template/zapsdtest/) — Scheletri delle interfacce/classi da completare e suite di test unitari `simpletest`
